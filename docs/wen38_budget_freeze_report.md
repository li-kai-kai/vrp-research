# WEN38 预算阶梯重跑与正式预算冻结

日期：2026-10-14。证据集：`outputs/budget_convergence_rerun/`。本报告只记录实测与判定，不构成收敛、算法优越性或现场标定结论。

## 设计

在 2026-10-13 的 consolidation 重构（09754fa）之后，用当前源码重跑 WEN38 预算筛检阶梯：预算 500/2000/5000/10000（80 次运行），并按协议预先声明的 confirmation budget 追加 20000（20 次运行）。共 100 次搜索；4 个规划模型 × 5 个配对 solver seed（60000–60004）；种群 32、交叉 0.90、变异 0.20。判据在 `protocol.json` 中跑前声明：HV 相对变化 ≤1% 且 IGD 绝对变化 ≤0.01，每模型 ≥4/5 配对，四模型连续两步。

源码指纹 a5942f81…。冻结集（`outputs/report_reproduction/`，指纹 f55a7149…）的 RunStore 未随仓库分发，且两套指纹不允许并入同一次分析；本集为独立重跑。验证：新跑 5000 档的三个模型对照与冻结旧集逐行一致，表明 09754fa 重构在数值上中性。

## 判定

| 步进 | HV 相对增益中位（Full / No-EC / No-HT / No-PR） | IGD 变化中位 | 小变化对数 |
|---|---|---|---|
| 500 → 2000 | +81.4% / +81.4% / +58.8% / +47.0% | 0.083–0.131 | 0/5 |
| 2000 → 5000 | +13.6% / +13.6% / +17.5% / +16.9% | 0.053–0.066 | 0/5 |
| 5000 → 10000 | +6.4% / +6.4% / +6.7% / +9.3% | 0.029–0.040 | 0/5 |
| 10000 → 20000 | +8.1% / +8.1% / +8.8% / +6.1% | 0.018–0.037 | 0/5 |

结论：`no_common_plateau_in_tested_range`（测试范围 500–20000）。**增益不随预算收缩**：后三步的 HV 中位增益都落在 +6%~+9% 每翻倍；在现行判据下，继续翻倍不会出现平台。

## 计时（描述性）

- 每评价成本在 500–10000 区间恒定（Full ≈ 0.042–0.044 s/eval）；Full@10000 单跑 441 s（7.4 分钟）。
- 20000 档每评价升至 0.078–0.081（Full）：该档使用 20 并发，超过本容器 13 核的 CPU 配额（`cpu.max=1300000/100000`），超配额并发会抬高单跑计时。该档计时不作为干净证据；500–10000 档并发 ≤8，不受影响。
- 全梯 100 次运行：phase 1 约 35 分钟（8 并发），phase 2 约 16 分钟（20 并发）；分析约 8–12 分钟。

## 冻结

正式实验的 WEN38 搜索预算冻结为 **10000**。判据未达成，按固定预算比较表述；不得写成搜索收敛。执行细节（含 phase 2 的 store 布局与并发差异）见 `outputs/budget_convergence_rerun/README.md` 与 `commands.sh`。

## 限制

- 单一物理实例（WEN38、instance seed 1），每档 5 个搜索重复；种子不是独立路网样本。
- 判据是描述性搜索稳定性筛检，不证明最优性；服务结果另行评审。
- 20000 档与其余档的 store 布局、并发不同；分析对目录布局无要求。

## A. 执行前沿质量

每个物理配置内合并四模型与两次求解前沿，通过共享 `pooled_quality_indicators` 构造共同参考和量化坐标。常数目标不放大浮点尾差。这里是 **IGD，不是 IGD+**；不改动共享指标。`ΔHV=HV(Full)−HV(简化)`，`ΔIGD=IGD(简化)−IGD(Full)`，均为正值有利于 Full。

| WEN38 solver | 对照 | ΔHV | ΔIGD |
|---|---|---:|---:|
| 60000 | No-PR | 0.448408 | 0.101833 |
| 60000 | No-HT | -0.149571 | -0.132694 |
| 60000 | No-EC | 0.000000 | 0.000000 |
| 60001 | No-PR | 0.528605 | 0.240349 |
| 60001 | No-HT | 0.291115 | 0.163220 |
| 60001 | No-EC | 0.000000 | 0.000000 |

WEN38 中 No-PR 两个种子均有利于 Full；No-HT 出现**种子反转**；No-EC 两次均零效应。不能用跨种子正均值掩盖 HT 反转，也不能将 EC 的零效应解释为容量约束普遍无价值。

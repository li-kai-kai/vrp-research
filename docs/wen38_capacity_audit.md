# WEN38容量来源与不绑定条件审计

日期：2026-09-25。本轮直接核对原论文PDF第35–37页、项目输入表、共享代码和Full执行快照。容量来源审计已经完成，后续未完成的是外部标定与改变假设后的验证。

## 来源和单位

原论文表16给出节点连接、自由通行时间与供需数量；表17给出维修时间；表18给出车型载重、数量及Occupied OD流率。论文没有逐边列出本项目使用的基础容量。项目按供应点连接和自由通行时间分档估算400–1200 pcu/h。每趟1/1.5/2/2.5 pcu、进度阈值0.30/0.50/0.70/0.80是项目假设。Occupied OD的300/500/800/1000 pcu/h不是每趟车辆当量。

每边每期容量=基础容量(pcu/h)×期初恢复比例×8h×容量倍率；无向边两个方向共享，救援去程逐车扣减pcu，当前不扣返程或背景交通。

## 充分条件

全网共享车辆趟次额度给出的单边使用上界：150×1+110×1.5+70×2+40×2.5=555 pcu。正费用简单路径不重复经过同一边。任一开放边的最小期额度下界为400×0.3×8=960 pcu；因此在当前规则下555<960，容量不会先于车队总额度绑定。

容量倍率s满足960s≥555时，这一不绑定充分条件成立；边界为0.578125。边界左侧只表示失去这条全局保证，不代表实际容量必然绑定。此结论依赖共享趟次、8小时周期、默认PR/HT、简单路线、救援去程和无背景交通，不能解释为真实汶川无拥堵。

# 当前范围与后续门槛

本分支整合截至2026-09-26的v2机制诊断、共同执行、预算和资源审计、并行NSGA-II与论文。普通GA、旧评价语义、旧动态实验及被替代的中间产物已移出工作树，仍可通过整合前的Git提交追溯。

Full是共同执行的建模假设，尚未现场标定。回放固定维修顺序、队伍分配和配送优先级，车型、路线、吨量由解码器重算。No-PR使用二元恢复；No-HT仅统一通行阈值，载重、PCU和趟次仍不同；No-EC取消边—周期容量扣减。

前沿质量、预选代表执行表现、同一方案预测偏差分别报告。代表在规划时按量化 `(F3,F1,F2)` 选择；执行后不重新挑选。先平均同一实例内重复，再对独立实例等权平均。

下一步先验证更高预算的搜索稳定性，冻结独立实例、种子与敏感性方案，再执行正式实验。已有并行计时不能替代模型效果、算法排名或收敛证据。

# 正式模型价值实验报告

日期：2026-10-15。证据集：`outputs/formal/`（模型轨 744 次运行 + 敏感性轨 240 次运行，同一源码指纹 `644784087ed2`）；设计见[正式实验协议](formal_experiment_protocol.md)。本报告区分实现、实测、执行侧统计与描述性结论；不含收敛、算法优越性或现场标定主张。

## 1. 数据与校验

- **模型轨**：S025 15 / S050 9 / M100 6 个独立实例 × 3 求解种子 × 8 个模型组合，算法 `nsga2`（pop 32、交叉 0.90、变异 0.20），预算 10000/5000/2000/10000（WEN38 单实例 ×3）。744 次运行、93 个完整八组合块，全部耗尽预算，单一源码指纹。
- **敏感性轨**：20 个格子 × 12 单元（S025 实例 1–6 × 种子 repeat 0–1）= 240 次运行；覆写抽查通过（4 队、容量档利用率 0.017→0.986、阈值档模型指纹变化）。
- **执行侧**：模型轨全部决策（14554 条）在共享 Full 环境重解码；两条回放管线（`replay_solutions` 与 `common_execution_analysis`）经逐位一致性校验。

## 2. 规划侧统计（`model_ablation_analysis`，每档 Holm）

- 实质效应仅两处：**EC → 最忙边利用率**（机械性，S025/S050 显著）与 **PR → 小车型占比**（S025 边际，Holm 0.073）。
- 目标与前沿质量（F1/F2/超体积/IGD）在规划侧全部未达显著——简化模型在自身假设内自洽。这正是"代价在执行时暴露"的前提。

## 3. 执行侧（代表决策在共享 Full 环境；单元 = 实例；每档家族 6 检验 + Holm）

| 档（实例数） | No-PR | No-HT | No-EC |
|---|---|---|---|
| S025（15） | ΔHV +0.202（Holm 0.043）；ΔF1 +0.037（0.030） | ΔHV +0.190（0.004）；ΔF1 +0.048（0.003） | 0（1.0） |
| S050（9） | ΔHV +0.295（0.023，9/9）；ΔF1 +0.101（0.039） | ΔHV +0.216（Holm 0.164 **未过**）；ΔF1 +0.067（0.039） | 0（1.0） |
| M100（6） | 均未过（1/6） | 均未过（1/6） | 0（1.0） |
| WEN38（3 种子） | ΔHV +0.303、ΔF1 +0.154（3/3，描述性） | 未检出 | 0（0/3） |

结论：**忽略 PR 与 HT 在执行时显著吃亏**（8 个真检验中 7 个过 Holm 0.05；唯一降级的是 S050 忽略 HT 的前沿质量）；**EC 在四个档、60 个实例单元上精确为零**。

**预测偏差**（规划代表 vs 执行）：No-PR 低估执行 F2（S050 +168 分钟；WEN38 抽查三颗种子 +16%/+53%/+68%，同时 F1 优于其预期 5–11%）；No-HT 低估 F2 更深（S050 +220 分钟）。WEN38 抽查的 Full 对照组偏差精确为 0，排除计算伪影。机制：二值恢复模型把"半恢复可达"误判为不可达，执行解码器按真实路况使用慢速捷径——双向误估。

## 4. 执行侧 2³（交互；`execution_2x3_analysis`）

- **HT 主效应与 PR×HT 交互效应精确相等**（S025：ΔF1 −0.0241、ΔHV +0.0948，Holm 0.003；S050：Holm 0.047）——结构性退化：二值恢复下"通"即全车型可通，车型阈值不作用，HT 的全部价值依附于 PR 制造的部分恢复状态。
- 与 EC 有关的主效应与全部交互精确为零。
- PR 主效应在 S050 过 Holm（0.047），S025 被 HT0 格子稀释；与"单因素关闭"对比（第 3 节）互为补充。

## 5. 处境条件化（`regime_conditioning_analysis`）

- 逐实例代价：S025 忽略 PR 有代价 12/15（−0.016…+0.194）；S050 8/9；M100 3/6；忽略 EC 全档 0/N——**"EC 零差异"没有例外**。
- 粗暴露指标（部分恢复边-期数）在实例间近似恒定，无法支持梯度条件化（如实记录）；锐利的处境证据来自：HT 的结构性依附（第 4 节）与 EC 绑定区探针的剂量-反应（第 6 节）。

## 7. 限制

- **M100 的"未检出"不可读作"机制无关"**：n=6、预算 2000（与规模混杂），功效不足。
- **WEN38 单实例**：仅描述性；其 No-PR 结果方向与合成档一致。
- 每档 3 求解种子（实例内重复，非独立网络）；执行侧检验家族按档预声明并 Holm 校正。
- **算法优越性不在本轮范围**（独立算法对照轨已取消）：`spt/vnd/nsga2_ls` 不进入正式实验，`nsga2_alns` 仅作成本探针记录。
- 容量/阈值/资源仍为项目假设，未做现场标定；敏感性档位是机制激活用的压力水平，不是标定主张。
- 粗暴露指标未能条件化 PR 的逐实例差异（第 5 节），如实保留。

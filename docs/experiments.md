## 2026-09-26 full-budget 并行 NSGA-II（RQ3/RQ4）

论文 `paper/ispa2026/` 的 RQ3/RQ4 正式实验，入口 `exp/parallel_nsga2.py`，
结果集 `exp/full_budget/`（`results.json` 保留每个 run 的完整前沿，`results.csv` 为摘要）。
共 **39 个 run**，全部用满预算，**前沿逐位一致（non-identical fronts = 0/39）**。

- **RQ3**：WEN38，预算 1600 / 种群 32，solver seeds {11,22,33} × workers {0,1,2,4,8} = 15 run。
  `workers=0` 是串行路径，已单独验证与仓库原生 NSGA-II **逐位一致**（budget 320/pop 16，
  front 19 点、320 次评估）。15 个 run 的前沿大小为 56/41/35（seeds 11/22/33），
  与每个种子串行 run 逐位相同，目标最大绝对偏差为 0，缓存命中数一致。
  新机器（13 核）实测：W=1 70.7s、W=2 38.4s、W=4 22.6s、W=8 20.9s；
  相对串行基线加速 1.81×/3.08×/3.34×（W=2/4/8），效率 0.92/0.78/0.42。
  **W=1 比串行路径略慢（0.98×）**——单 worker 只付进程与 IPC 开销、拿不到并行收益。
- **RQ4**：S025/WEN38/S050/M100 规模阶梯，pop 32，seeds {11,22}，预算 1600/1600/800/400。
  W=8 加速比 3.34×/3.36×/4.46×/4.88×，**效率随单次评估粒度上升**而非随节点数上升：
  W=1 单次评估 WEN38 44ms、S025 48ms（更小但更贵）、S050 196ms、M100 617ms，
  对应 W=8 效率 0.42/0.42/0.56/0.61；两个细粒度实例在每个 W 上都最低，两个粗粒度最高。
  每个 (实例, 种子) 块内四种 worker 数的前沿、缓存命中数、pooled HV/IGD 全部相同。
- 效率在任何 W 下都随 W 下降：每代可并行的评估数**至多等于种群规模**（缓存命中后更少），
  这是并行宽度的硬上限，不随实例增大而放宽。因此**机制感知的降保真与并行评估是替代关系
  而非互补关系**——两者应部署在相反的适用区间。

## 机制适用条件诊断（2026-09-20）

回答"PR / HT / EC 在什么条件下真正改变决策"，结论与分区证据见
[机制适用条件诊断报告](mechanism_applicability_report.md)。要点：

- 区分三个层次：**机制暴露（必要）→ 配送参与 → 目标效应**。S025 的 80 个固定决策中，
  `*_allocations_changed` 与目标是否变化**逐行一致**（PR 30/30、HT 19/19、EC 0/0）；
  **但跨规模复核后这条不再普遍成立**。两个方向必须分开：
  objective → dispatch **无例外**（360 对）；dispatch → objective 在 **M100 上破 3 例**
  （关闭 HT 使车型 2 / 3 在通行性上可互换，配送器对同一平局作出不同选择，目标逐位相同）。
  因此该判据是**保守的筛选判据（不漏报、会多报）**，不是定论判据。
  只看可达性或候选路径会漏判——它们只是必要条件。
- EC 的绑定边界（1120 个网格单元，S025/S050/M100 三个规模、两类拓扑）：
  利用率 < 0.85 从不绑定（合并 **0/776**，下边缘在三个规模上都稳定）；
  0.85–0.97 过渡（合并 22/48 = 46%）；
  ≥ 0.97 高度集中但**不是充分阈值**——合并 292/296（99%），M100 上有 4 个反例。
  更锐利的判据是 `capacity_reroutes > 0`（合并 **296/296** 全部生效，无例外），
  但它仍不是定义。**不得把 0.97 当作正式场景选择的硬阈值。**
- 瓶颈判定改用**逐资源放宽对照**（三轴都是相对当前场景的倍数且必须 > 1）：
  车队在两类场景中都绑定；随机损伤场景中车队与供给**同时**参与，不是单一瓶颈。
  道路容量在两类场景的**基准标定**下相对当前值放宽 ×2 均不改变目标，因此基准区域道路容量不绑定；
  **同一探针在标定后的 transition / binding 区会触发**（走廊场景 ΔF1 −0.182 / −0.322 / −0.190），
  与独立的 EC on/off 结果逐格一致，所以基准处的 0 是真实的"不绑定"而非探针失灵。
  **此前的"总供给受限"结论已撤回**——方向错误；此前"道路容量在 0.002 绝对标度下不绑定"的说法
  也作废，那次探针实际是把约束**收紧** 25 倍。
- HT 的适用条件**不只是拓扑**：`damage_strategy="critical"` 在 S025（0 条桥）上静默退化为随机损伤，
  此前"桥接损伤使 HT 提高约 3 倍"的结论**已撤回**；四格对照显示提升实际来自 `node_role_strategy="separated"`。
  同时，"必经走廊"**不是** HT 的必要条件（不是割边也可能改变最短路）。
- 走廊/桥接类实验现在**运行前断言** `damaged_bridge_count > 0`，标称与实际不符即拒绝运行。

## WEN38 天然 HT corridor 诊断（2026-09-20）

在真实 WEN38 路网（38 节点 / 51 边 / 16 受损 / 3 供 35 需）上回答"是否天然存在 threshold-sensitive
corridor"。结论与四级证据见 [WEN38 天然 HT corridor 诊断报告](ht_natural_corridor_report.md)。要点：

- **16 条受损边中 15 条是结构 corridor，其中 11 条不是桥**；按 OD 依赖度排序前两名（17-22、1-17）
  都是普通道路。**HT 不依赖桥。**
- 四级分离：结构 15 → 动态 16 → dispatch 19/20 决策 → 目标 19/20 决策。
- 效应集中在**成本**：关闭 HT 使 F2 在 18 个决策下降、1 个上升（`random_17` +0.3%）、1 个不变，
  非零均值 −7.2%、中位数 −3.7%，而送达量与 F1 几乎不变。
  **符号是经验发现，不是解析推论**：可行域包含关系不蕴含目标单调性（greedy decoder 不保证更优解），
  此前的"必然下降"说法已撤回。
- **60 个半真实 overlay 无一 inactive**（58 个 strong-active、2 个 active），
  损伤均匀性经测量（抽中桥比例 0.153 对基线 0.157）。
- 小预算 Full vs No-HT 搜索：代表按**预先固定的最低 overlay seed** 选（每层一个），
  Full 自回放 99 个决策误差 0；两个代表的 No-HT 决策回放后 36/50、28/47 目标改变。
  这是**诊断性代表结果，不是自然场景总体均值**。
- dispatch ↔ objective **两个方向在 WEN38 上均零反例**（与 M100 的 3 例充分性反例对照）。

## 下一轮研究任务

**优先级已按机制诊断重排**：在机制是否参与决策尚未确定之前，不应扩大统计规模。

1. **把适用条件做成场景选择规则（第一优先）**。正式诊断应至少覆盖一个不绑定区、一个过渡区、一个绑定区，
   并如实报告三者；分区标定应按场景测量（现有 `mechanism_zone_search.py` 已改为按 (场景, 种子) 标定），
   而不是沿用固定 `capacity_scale`——走廊拓扑上固定标度会让标称"transition"的格子落在 0.25 ~ 0.95 之间。
2. **HT 需要真实的瓶颈拓扑（第一优先）**。走廊与 separated 角色都是构造出来的；
   应先检查真实/半真实网络的桥接结构与需求分布，确认是否存在天然的"仅部分车型可通行的最短路"。
3. **固定模型价值诊断方案（第二优先）**。在已定位的绑定区内，用统一 Full 执行回放测量忽略各机制的决策损失；
   诊断必须给出全方案影响分布，而不是只看均值或固定方案。
